# Offline acceptance scope

Read only the consumed v6 label-qualification attempt, its frozen package and
source train tape. Do not read sealed task-confirmation data, instantiate an
environment, import NumPy/PyTorch, load a checkpoint, or create an attempt.

Recompute the original coverage rule; retain unknown and NOOP masks. Separate
physical task outcome, host receipt, first-command attribution, one-step utility,
whole-continuation utility, infrastructure settlement, and export identity.
Candidate rows, same-task action pairs, and repeated communication events are
not independent statistical samples. Eight parents are development evidence.

Write analysis and a small per-candidate table only in this new directory.
Hash the old package and attempt before and after all reads. Report all digest
mismatches without updating old manifests. Any derived attribution correction
must retain the original value and source identity; do not rewrite old data.

The research decision follows the user's three allowed branches. A label-chain
success does not demonstrate learnability, a world-model increment, or GPPO
task benefit. Do not invent a post-hoc training pass threshold.
