For new collection, `ProductionDataCollector._checked_environment_config()`
constructs `M10Config` from the frozen config contract, checks the digest and
all values before environment construction, and writes the runtime record from
the exact object passed to `M10Environment`. A mismatched mode or deadline
basis fails before reset. This repairs provenance for future collection; it
does not alter the source data or retroactively change a result.
