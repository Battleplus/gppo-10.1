# One-shot experiment design

The dynamic run is a single chained attempt with no retry, budget borrowing,
scene replacement, extra seed, or post-result tuning.

1. Verify the 219 training and 68 model-selection labels and the frozen source
   identities. Stop before collection if the audit fails.
2. Collect one new fixed-Hungarian prediction-confirmation unit for each of
   eight preselected parents and three external repeats. A unit with no
   qualifying opportunity is retained as missing; it is not replaced.
3. Train A and B with seeds 7101, 7102, and 7103. Each seed is selected only
   on the same model-selection parents. Both variants use complete-window
   batches and equal window weighting.
4. On the eight new prediction parents, persist the complete per-candidate
   trace and compare A, B, current-public, and transparent-history scores.
5. Enter the four-arm task stage only when the frozen prediction gate passes:
   Hungarian, transparent one-shot plus Hungarian continuation, A one-shot
   plus Hungarian continuation, and B one-shot plus Hungarian continuation.

The task stage is conditional and remains unexecuted when the prediction gate
fails. It does not reinterpret a prediction result as GPPO or world-model
evidence.

The dynamic budget is generated by `freeze_package.py`. Its new confirmation
ceiling is 24 parent-repeat units and 600 branches; old labels are not
re-collected. Training and evaluation ceilings are doubled only where A and B
both require the same three-seed computation. All active state is contracted
to WSL native storage, with one verified export after settlement.
