# A/B launch wiring repair

This is a new, independently sealed preparation package for the frozen
relative-utility A/B comparison. It does not run an environment, model,
checkpoint, or training call during preparation. `RESOURCE_REQUEST.json`
remains `NOT_APPROVED`; authorization is supplied only by the exact external
one-shot token at a later launch.

The package retains the previously validated Windows -> Ubuntu-24.04 -> WSL
native staging -> supervisor -> worker -> settlement -> verified export chain.
The task stage is gated by both the A/B effect gate and strict improvement over
the transparent-history baseline.
