# W1 Action-Conditioned Task Outcome Label Repair v1

This is a read-only diagnosis and preparation package. It does not run the
environment, initialize or load a model, run a forward pass, train, create an
attempt, or consume dynamic authorization.

Run the offline audit with `audit_saved_windows.py` and the synthetic contract
tests with Python's unittest discovery. The audit reads the sealed
`world-model-windows.jsonl` and records source-code evidence without changing
that export.
