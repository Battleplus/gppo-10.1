# W1 数据与标签可用性

本表依据 `EAWM-JEPA-reuse-audit-20260929.md`、`world-model-interface-log-audit-v1` 及修复后运行归档的静态记录整理，未重新读取封存任务集，未运行环境或模型。

| 目标 | 当前可用性 | 时间/身份合同 | 首轮处理 |
|---|---|---|---|
| 下一公开状态表示 | 部分可用。训练记录有相邻公开 `steps.jsonl` 的 1906/2048 对，评估有106/114对；末行只有hash | 目标必须是下一次实际公开观测，receipt 不得晚于决策边界；末行缺失保持 unknown | 仅开发/接口测试；确认数据需新采集并完整落盘 |
| 公开字段变化 | 可从相邻公开字段构造，需known/valid和实体身份 | 测量时间与接收时间分开；重复遥测不等于物理不变 | 可作为 masked public-state target |
| 命令接受 | 有首反馈类别的历史证据 | 接受反馈不等于物理完成或主机确认 | 作为单独标签，不并入任务完成 |
| 物理完成/过期 | 事实分支有结果；未执行候选没有反事实真值 | 分支标签只在 target，不能进入当前输入 | 只评价真实执行/隔离分支 |
| 主机确认 | 记录中存在 unknown/确认边界 | 与物理完成分开 | 独立 event head，unknown 不填零 |
| 当前 continuation identity | 历史导出只保留扁平向量、哈希及计数，完整身份缺失 | 不能从分支后审计记录反推决策前身份 | 新采集必须保存可读 continuation IDs |
| 自动事件 | 任务状态变化、损坏首次公开、连接变化有部分有效样本；紧急首次公开和低能量穿越无正例 | 仅预测“公开看到的事件”，不预测隐藏随机命运 | 首轮保留有效mask和类别不平衡报告 |
| 一步任务后果残差 | 新采集可在同一冻结父状态对全部合法候选执行一个决策间隔 | 透明位置/基础能耗先计算；学习标签只保留透明项未解释的原效用、时间和占用残差 | 用于候选排序确认；不解释为GPPO长期价值 |

## 结论

当前记录足以验证合同和开发接口，不能直接支撑独立确认集上的 JEPA 预测门。旧数据不能包装成新确认集；缺少完整 continuation 身份和末行下一观测时，不补造标签。

## 公开输入适配边界

`w1_public_adapter.py` 是不持有环境状态的纯适配层。它接收已经生成的 M-10
公开 observation 和显式 telemetry sidecar；测量时间、接收时间、sequence 和
message identity 不从 `flat` 或分支结果推断。生产调用必须显式传入已审查的
`graph5_from_m10_observation` builder；builder 只收到公开字段白名单，默认路径
只保留公开 graph payload，避免准备包导入环境执行入口。出现决策后 receipt、
冲突重复或缺失 continuation policy identity 时拒绝构造输入。严格候选评分入口
只接受 `W1PublicInput`，并要求显式 history encoder 从冻结 payload 构造128维历史；
公开字段、图和续行策略身份共同进入 trace 身份。
