# W1 action-outcome learning loop

This is the independent, `NOT_APPROVED` launch-repair package for the same
finite learning experiment. Research logic and dynamic limits are unchanged.

- `learning_schema.py`: strict 827-dimensional public-input and true-branch contract
- `learning.py`: lazy PyTorch MLP, training loop, checkpoints, and inference
- `prediction_evaluation.py`: parent-macro error, ranking, regret, and stage gate
- `transparent_baselines.py`: current-public and public-history estimates
- `runtime_backend.py`: repaired W1 branch collection and paired task execution
- `pipeline.py`: collection, training, evaluation, and conditional task orchestration
- `experiment_matrix.py`: frozen parent split and exact budget derivation
- `launch_once.py`: Windows-only identity/token gate and structured WSL entry
- `wsl_stage_and_launch.py`: Linux-only staging, supervision, settlement, and export

Large diagnostic JSONL files remain local and are excluded from GitHub. Their
hashes and counts remain indexed. The raw launch token is outside this directory
and is never archived.

The prior attempt and its partial `E:\home\asus` staging evidence remain intact
and are never cleaned or reused.
