# 一次性实验设计（待批准）

本文件将采集、世界模型训练、策略训练、预测确认和条件任务对照作为一次申请的阶段合同。`RESOURCE_REQUEST.json` 当前保持 `NOT_APPROVED`，因此所有动态数量均是未冻结字段，不能据此启动。

## 固定对象

- 方法：G0、T、G1、G2、H；GES 不进入首轮；
- 模型：W1 Graph-5、25动作（24 UAV-task候选+NOOP）；
- 种子：世界模型和策略各3个，编号在授权文件中固定，禁止按结果挑选；
- 输入：决策前公开图、history、字段 known/valid/age、measurement/receipt time、已确认 continuation；
- 标签：下一实际公开状态、公开事件、接受、物理完成、主机确认分别记录；unknown 保持 unknown；
- 后果时间范围：候选首动作到下一个原生决策时刻；不把固定Hungarian终局收益作为GPPO价值。训练/选择各父场景一个预定窗口，预测确认每父场景repeat一个窗口；
- 策略：世界模型训练并冻结后再训练 GPPO/适配器；不做奖励塑形或想象轨迹PPO。

## 阶段与停止

1. 静态合同和生产入口预检：失败即停止；
2. 按父场景采集新确认标签：缺少完整下一公开状态或 continuation 身份的窗口不进入训练，不补零；
3. G1/G2 三种子训练，选择集按父场景隔离；
4. 预测确认：报告 state MAE/RMSE、event Brier/NLL/ECE、pairwise direction、regret、种子差异，并按 `protocol.md` 的固定三项增量门判定；
5. 仅预测门通过才训练 G0/T/G1/G2 策略并执行 G0/T/G1/G2/H 任务对照；
6. 结算时分开记录特征、预测、融合、选择和完整进程成本；任何技术异常封存，不自动重试。

## 统计口径

父场景为独立分析单位；repeat 和候选行不是独立父场景。无机会父场景保留、不填零、不补选；宏平均分母只包括有完整窗口的父场景，但少于8个即覆盖门失败。并列按预先固定的最小动作编号处理，同时报告并列数。若 G1/G2 只在少数父场景改善，报告集中性，不升级为可重复增益。

## 资源推导

批准申请必须从冻结父场景数 × 每场景窗口数 × 候选数 × 三种子 × 训练batch/epoch 推导环境步、reset、候选分支、forward、update、checkpoint、wall、CPU和存储；共享标签采集只计一次。历史余额不转入，不能复制旧标量实验预算。
