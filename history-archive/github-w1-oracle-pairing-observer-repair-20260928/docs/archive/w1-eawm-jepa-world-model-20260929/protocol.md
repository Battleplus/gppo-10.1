# W1 透明动力学辅助、任务相关动作条件世界模型协议

状态：`NOT_APPROVED`。本文件是一次性准备协议，不是运行授权。

## 固定主张与反主张

- 主张：动作条件公开历史表示能在透明动力学之外提供可验证的任务相关候选排序信息。
- 支持主张：自动公开事件监督相对无事件辅助的相同 JEPA 主体有独立增量。
- 反主张：收益只来自额外参数、场景选择、通信运气或更高成本。

## 首轮方法

| 臂 | 内容 |
|---|---|
| G0 | GPPO + 合法公开历史，无世界模型候选先验 |
| T | 同一 GPPO 接口 + 透明位置/距离/能耗/理想完成时间特征 |
| G1 | GPPO + W1动作条件JEPA + 公共字段读出，无事件辅助 |
| G2 | G1 + 自动公开事件监督；主体、数据、优化器、选择规则一致 |
| H | Hungarian 强规则 |

GES 不进入首轮主矩阵；只有 G2 的事件目标在独立确认上通过后，另行冻结 G3。

G1/G2 共享一步决策间隔的6维任务后果残差头：命令接受、公开执行状态变化、完成时间偏差、
基础能耗之外残差、按原奖励/偏好/折扣定义的剩余效用残差、资源竞争占用。
每项都有独立有效 mask；NOOP 的目标任务项无效而不是零。候选先验分数固定为
透明原效用估计加第5项本步原效用残差，避免完成、过期、能耗重复计分。该标签
不使用 Hungarian 终局续行，也不声称是 GPPO 长期价值；长期价值仍由 GPPO 在真实奖励上学习。

## 数据边界

训练、模型选择、预测确认、任务确认按真实 `scenario_id/tape_id/seed` 分组隔离。已分析父场景只能作开发证据。输入只允许决策前公开 graph/history、字段有效性/age、已确认 continuation 和自身已知动作；未来观测、分支标签、私有状态和真实通信命运只能进入 target。

## 推进门（在确认数据开放前冻结）

1. 技术合同门：无未来输入、25动作映射、事件有效mask、候选逐行 trace 和成本账闭合。
2. 预测门：8/8预测确认父场景至少各有一个完整合法窗口；G1 相对透明 T 的父场景宏平均 regret 至少降低 `0.005` 且至少4/8父场景不劣；G2 相对 G1 的宏平均 regret 至少降低 `0.0025`、event Brier 至少降低 `0.01`，且至少4/8父场景不劣。masked state MAE/RMSE、事件 NLL/ECE、pairwise direction accuracy 同时报告但不替代上述门。阈值依据旧动作排序实验的0.005最小区分尺度，并将更小的0.0025用于事件单因素增量；样本量仅支持本批父场景范围的判断。
3. 任务门：通过预测门后才训练 G0/T/G1/G2 策略并运行 G0/T/G1/G2/H 真实任务对照；G2 相对 Hungarian 的父场景宏平均效用增量至少 `0.01`，G2 同时必须严格高于 T 和 G1，且至少4/8父场景不劣于 T；G2 自身完整决策 CPU均值 `10ms`、wall p95 `50ms`。其余方法成本单独报告，不混合验收。

## 时间语义

`t` 是决策时刻；`measurement_at` 是物理测量时刻；`received_at` 是控制端可用时刻；`age=t-measurement_at`。只有 `received_at<=t` 的记录进入输入。下一公开状态是 `t+1` 的实际控制端观测；主机确认、物理到达、任务完成分别记录。

## 运行顺序

静态合同测试 → 只读生产入口预检 → 批量标签采集 → G1/G2三种子训练 → 独立预测确认 → 仅预测门通过时进行五臂任务对照 → 结算、逐候选导出和哈希核验。任何技术停止封存，不自动修复、重试、换场景或追加种子。
