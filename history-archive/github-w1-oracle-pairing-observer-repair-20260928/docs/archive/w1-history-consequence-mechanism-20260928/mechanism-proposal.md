# W1-light公开历史与动作后果：一页机制假设

状态：机制提案完成；没有动态、模型或训练授权。2026-09-28。事后开发分析，仅使用修复运行时的原8父场景。

## 具体假设

在保持原W1-light、公开mask、ACK/lease门禁、奖励与强规则不变时，显式利用“各字段的测量时刻＋历史公开观测＋自身已提交动作＋公开确认的continuation”形成当前状态的不确定性估计，再预测合法动作的接受风险、按时物理完成与能耗，可能比当前状态预测、透明时序估计以及已有循环模型更有效地指导调度。

这是一条“公开历史→当前状态估计→动作后果”的机制假设。状态估计不是动作后果世界模型的全部；加入GRU或历史本身不是创新，也不证明收益。

## 现有证据与已有能力

对修复后56个episode、774条决策完整扫描；逐条重建PublicMemory后，所有已选动作都属于有效候选。367个非NOOP动作选择中，全部有已知UAV字段age>0，88次至少一个字段age>1秒，40次x/y测量时刻不同。上述阈值仅描述分布，不是挑选下一轮窗口的门槛。记录包含9次resource_unavailable及8次command_lost反馈（仅这367行）；不能把遥测陈旧与拒绝并存解释为因果关系。

实例：FULL在validation-0007、t=7选择uav-0→task-4（原steps.jsonl第764行），x来自t=5而y来自t=6，能量来自t=5；候选为[4,10,24]，事后反馈resource_unavailable。存在可比较选择，但尚无证据证明合法历史能预判拒绝，或另一个动作会更好。反例：Hungarian在validation-0001、t=6的拒绝（第129行），所有UAV字段age均为1秒；不能把age>1简单设为风险真值。全部成功和失败选择均保存在decision-evidence.jsonl，不只保留这两个案例。

PublicMemory已保留最新测量、完整公开观测历史、自身pending及ACK已知continuation；所有方法共用过滤。search已用age修正旅时和能量。PPO、GPPO_noWM、FULL已有循环策略表示；FULL另有动作条件GRUCell世界记忆。runner延续这些hidden，因此“原模型不知道历史”不成立。现有模型是否充分利用历史尚未知。

## 可检验对象与公平对照

只提出一条主线：**异步字段和执行历史的显式状态估计是否具有增量信息，且能通过动作后果预测产生任务收益。** 不改变任务分布来制造优势，不重新开启已关闭的首窗口oracle。

未来若另行批准验证，固定相同公开执行过滤，比较：当前完整公开状态（含age/valid和同一执行过滤）＋候选动作；相同输入加合法历史的预测器；使用相同历史的透明时序估计；原循环FULL/noWM及原四种规则。必须把信息增量、显式监督与网络容量的变化分开，不将多个变化的总收益称为世界模型独立贡献。

输入不得包含本步执行后的feedback、communication_delta、隐藏故障时间表、丢包真值或未来消息；历史中的反馈也须证明它当时通过合法接口可见，不能直接把info日志喂给模型。新鲜遥测、ACK、lease、版本和合法动作不能由预测伪造。

目标分层：接受概率先按实际发送/接受过程分离；任务完成与能耗对应明确的首动作和固定续行范围。主机确认unknown保留，不作失败。现场状态真值只能作为经独立授权取得的监督/评价标签，不作为模型输入；目前日志不足以建立完整同状态反事实训练集。当前数据不能判断预测优势或因果收益。

## 证伪与去留

若公开历史在独立父场景上不能超越含age的当前状态与透明历史估计，则历史增量假设失败；若仅改善状态误差却不改善动作后果排序或实际调度，则世界模型收益假设不成立。最终仍须相对原强规则达到冻结效用增量0.01，并满足CPU均值10ms及wall p95 50ms，不能以预测准确率替代任务收益。未来测试划分、预测指标及预算需预先确定，本提案不新增门槛或授权。

Hungarian与EDF在现有开发评价已实现全部物理按时完成；剩余收益主要只能来自能耗、原效用时间折扣等，不能靠更改奖励追求主机确认收益。现有证据**支持提出机制，不支持立即训练**。下一项具体缺口是合法历史相对“当前状态＋现有公开记忆/age规则”的增量可预测性，不能用GRU存在或陈旧观测计数替代验证。
