# Interpretation limits

1. This is a development result over eight previously observed W1-light parent scenarios and three fixed repeats. It is not an independent confirmation set and does not establish general engineering performance.
2. The intervention is limited to the first qualifying public decision window. Every branch then uses the same frozen Hungarian continuation. Failure closes this specific intervention, not later windows or every possible action-consequence target.
3. Oracle gain is nonnegative by construction because the Hungarian first action is included among the maximized candidates. A nonnegative gain is not repeat stability.
4. The hindsight winner can benefit from exogenous random outcomes unavailable from public history. Its gain is an optimistic ceiling, not predictor performance or learnable expected gain.
5. Only three units had both first commands accepted and gain at least `0.01`. One unit involved different acceptance eligibility. Acceptance mismatch alone is not evidence for a useful predictor.
6. Action numbers are comparable only within the same saved public state. Different repeats have different public-state hashes, so winner action IDs cannot be treated as a stable target across repeats.
7. The 182 unknown labels are candidate-branch task-level host-confirmation fields out of 864 such fields. They are not 182 independent scenarios, not 182 physical failures, and not accounting unknowns.
8. Utility remains available because it uses the complete finite reward sequence and not the missing confirmation field. Host-confirmation analyses must preserve unknown as a separate category.
9. This run used no model. It neither measures a world model nor supports attributing any result to GPPO, FULL, or model training.
10. The historical 10 ms FULL cost failure, prior technical stops, known accounting gaps, and all historical resource consumption remain part of the research record.

The only authorized conclusion is that the frozen first-window, Hungarian-continuation oracle ceiling did not meet its breadth requirement: 2 of 8 parents passed versus 4 required. No automatic training, expansion, threshold change, or follow-on experiment follows from this report.
