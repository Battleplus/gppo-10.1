**当前状态：v7 最终包已经在服务器完成原子部署和无授权 `--preflight`，但尚未获得正式执行授权，也没有创建 token、attempt 或启动训练。** 目前正在做的是一个世界模型后果排序的窗口等权消融：验证“候选对按窗口等权归一化”是否比原 batch 内候选对等权更稳定。它是开发研究，不是已经证明有效的改进。

## 现在在做什么

- 复用已经核验的 288 个历史窗口：174 个 `complete`、114 个 `no_opportunity`；只把 58 个训练窗口用于训练，不重新采集环境数据。
- 新初始化六路世界模型：A/B 两种排序损失归一化方式 × 3 个随机种子。A 对 batch 内所有有效候选对等权；B 先在每个窗口内平均，再对有效窗口等权。
- 每路训练 40 epochs、320 次更新，共 1,920 次世界模型更新。GPPO 更新和任务 episodes 固定为 0。
- 六个 checkpoint 全部完成并通过严格恢复核验后，才在 24 个预先隔离、尚未查看的评价父场景上做共同反事实评价，比较 B−A regret、重大损失、父场景稳定性和跨 seed 稳定性。

## 已完成的准入检查

- 最终 v7 包已部署到服务器正式目录，387 个登记文件和三项冻结摘要一致，没有 `.pyc`、`.pyo` 或 `__pycache__`。
- 服务器 runtime 为 Python 3.11.16、PyTorch 2.7.0+cu128、NumPy 1.26.0；CPU0、单线程和 GPU 禁用检查通过。

- 本地开发沙盒的排序回归也通过，但它只证明公式、窗口身份对齐和置换不变性，不替代服务器正式运行结果。

## 最终四臂任务结果

八个任务父场景 × 三个 repeats，保留三策略种子。G0/T/G1 各 72 episodes，H 共享 24；世界模型在 GPPO 阶段冻结，不更新。

| 方法 | 任务效用 ↑ | CPU 均值 ms ↓ | wall p95 ms ↓ |
|---|---:|---:|---:|
| G0：GPPO，无世界模型先验 | 0.245637 | 27.159 | 90.574 |
| T：GPPO＋透明先验 | 0.245637 | 28.835 | 98.974 |
| G1：GPPO＋冻结世界模型先验 | 0.236845 | 51.073 | 150.705 |
| H：Hungarian | **0.336046** | **12.484** | **45.090** |

G1 相对 G0/T 为 **−0.008792**，相对 H 为 **−0.099201**。相对 T 仅 3/8 父场景不劣、1/3 种子为正；父场景配对 bootstrap 95% 区间为 **[−0.023324, 0.008298]**。H 在本次完整计时口径下 CPU 也超过 10ms，不能宣称所有实用成本标准均通过。

**可支持的结论：G1 学到了有用的离线候选排序信息，但本方案没有将它转化为 GPPO 任务收益。** 透明参考在预测评价中全选 NOOP，且标签续行固定为 Hungarian，因此预测门通过不能等同于强规则优势或 GPPO 价值预测成功。

此前离线 regret 为透明参考 **0.234002**、G1 **0.050967**、G2 **0.101352**。这项 G1 正结果保留，但不能覆盖上面的任务负结果。完整预测指标见[世界模型报告](evidence/world-model/RESEARCH_REPORT.md)。
