## 最终四臂任务结果

八个任务父场景 × 三个 repeats，保留三策略种子。G0/T/G1 各 72 episodes，H 共享 24；世界模型在 GPPO 阶段冻结，不更新。

| 方法 | 任务效用 ↑ | CPU 均值 ms ↓ | wall p95 ms ↓ |
|---|---:|---:|---:|
| G0：GPPO，无世界模型先验 | 0.245637 | 27.159 | 90.574 |
| T：GPPO＋透明先验 | 0.245637 | 28.835 | 98.974 |
| G1：GPPO＋冻结世界模型先验 | 0.236845 | 51.073 | 150.705 |
| H：Hungarian | **0.336046** | **12.484** | **45.090** |

G1 相对 G0/T 为 **−0.008792**，相对 H 为 **−0.099201**。相对 T 仅 3/8 父场景不劣、1/3 种子为正；父场景配对 bootstrap 95% 区间为 **[−0.023324, 0.008298]**。H 在本次完整计时口径下 CPU 也超过 10ms，不能宣称所有实用成本标准均通过。

**可支持的结论：G1 学到了有用的离线候选排序信息，但本方案没有将它转化为 GPPO 任务收益。** 透明参考在预测评价中全选 NOOP，且标签续行固定为 Hungarian，因此预测门通过不能等同于强规则优势或 GPPO 价值预测成功。

此前离线 regret 为透明参考 **0.234002**、G1 **0.050967**、G2 **0.101352**。这项 G1 正结果保留，但不能覆盖上面的任务负结果。完整预测指标见[世界模型报告](evidence/world-model/RESEARCH_REPORT.md)。

## 当前下一步

优先诊断三件事：Hungarian 续行标签与 GPPO 实际续行是否匹配、先验为何很少改变动作、完整决策时间主要花在哪里。先用已有训练/选择材料定位，再决定是否准备单因素改进和新的隔离验证；详细建议见[下一步](docs/NEXT_STEPS.md)。这属于待开展工作，不是已证明的失败根因。
